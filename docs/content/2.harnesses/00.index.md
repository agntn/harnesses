Each page is generated from the same registry the package ships, so a path here is a path `getHarness(id)` returns. The prose is mine; the tables are not.

::harness-roster
::

"Headless" lists the mode families `invoke()` can run; each has a structured variant where the CLI has a JSON output flag. Read-only means the CLI itself keeps the run from writing: Codex and Grok through `--sandbox read-only`, Pi and Claude Code through a tool allowlist. Copilot is the one harness with an agent mode and no structured variant.

## Audio and video

`capabilities.audio` and `video` are `true` only where a native route puts that medium into model context. Antigravity has both, Gemini CLI has audio through `read_file`, the other eleven have neither verified. Voice dictation that becomes text does not count, and neither does an MCP tool that transcribes. `false` means nothing was verified, not that every provider and extension was disproved. Each page states what was checked.
